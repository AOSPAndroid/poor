# Swing stocks

Trace disclosed purchase -> specific company exposure -> dated catalyst -> possible price response. Assess later sales, disclosure lag and whether the stock has already moved. Shared purchases count distinct households, not transaction lines; distinguish stock from options and acquisition from exercise. Do not treat falling since disclosure as automatic value.

For a supported long hypothesis supply an observable above/below entry level, invalidation/stop, conditional target and evidence-based levelBasis. These are scenarios, not verified future prices. Use the supplied completed close, 20-session range, matched S&P 500 proxy return and turnover. Unknown currency, stale data or insufficient history precludes a supported entry assessment. Daily closes do not prove an intraday executable fill. Consider earnings gap risk and never imply a stop guarantees an exit price.

The code evaluates reward/risk using the worse of the proposed entry and latest close, with an explicit 10-basis-point cost assumption per side. Its 2:1 threshold is a research screen, not a validated strategy. A target or stop already passed needs a fresh thesis. If no sensible setup exists, say wait and state exactly what would change that.


## New catalysts on older positions
A months-old disclosure can supply context for a new official announcement. Start with supplied exact catalyst URLs and dates, then test company economics and counterevidence. A conditional government loan is not funded cash or a grant. Treat news headlines as discovery only. If verification failed earlier, independently retrieve the original document rather than repeating the same broad search. Report the exact missing evidence.
